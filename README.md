# Task 5: Decision Trees and Random Forests

## Objective
To understand tree-based classification, overfitting, ensemble learning, and feature importance.

## Dataset
Iris dataset from Scikit-learn.

## Tools Used
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Work Completed
1. Loaded and explored the Iris dataset.
2. Split the data into training and testing sets.
3. Trained and visualized a Decision Tree Classifier.
4. Analyzed overfitting by changing tree depth.
5. Trained a Random Forest Classifier.
6. Compared the accuracy of both models.
7. Visualized Random Forest feature importance.
8. Evaluated both models using 5-fold cross-validation.

## Results
The Decision Tree and Random Forest models were evaluated using test accuracy and cross-validation. The feature importance plot shows which flower measurements contributed most to the Random Forest's predictions.

## Conclusion
This task provided practical experience with Decision Trees, Random Forests, overfitting control, model comparison, and cross-validation.
